# 方向三 · 像素小人 — 动画规格（ANIM-SPEC）

> 前端（小前）· 2026-10-26 · 配套 `d3.html`（横排展示）、`d3-vertical.html`（纵向走廊 = 正式侧栏形状）
> 接正式代码（`client.js`）的 1:1 依据。所有时长是 **1× 速度**下的值。

---

## 0. 网格

| 用途 | 网格 | 说明 |
|---|---|---|
| 横向 demo（`d3.html`） | 32 × 40 | 人形 36px 高，4× 展示 / 32px 简化稿 |
| **纵向正式版（`d3-vertical.html`）** | **44 × 46** | 原生重画，不是缩放；人形 y2–y43，阴影 y44–45 |
| 圆形头像 | 36 × 36 / 24 × 24 | 内容裁在 r=16 / r=10，2px 状态环压边缘 |

**通用纪律**：只允许整数像素与 2×/4× 整数倍放大；`step-end` 逐帧；**不做旋转**（1–2° 在 32–44px 上只会糊出半透明边）；
三阶明度用 `color-mix` 现算（`lit 16%` / base / `dim 26%`），不新增调色板。

**44×46 的解剖**（比 32×40 多出来的宽度用在哪）：
头 14×12（x15–28, y6–17）、发 y2–6、眼 2×2（x18/x24, y10）、眉 1px、鼻 1px、嘴 3px、颈 4px 宽；
躯干 22×13（x11–32, y19–31）、**2 处衣褶**；手臂 4px 宽 + **拇指 + 指节**（y31–34）；
腿 7px 宽 ×2（y32–41）、鞋 9px 宽（y42–43）。

## 1. 走路循环（4 帧 / 640ms）

| 帧 | 姿态 | 左鞋 | 右鞋 | 身体 |
|---|---|---|---|---|
| F1 0ms | 接触 | x−1 | x+1 | y0 |
| F2 160ms | 通过 | y−2（抬起） | 原位 | y−1 |
| F3 320ms | 接触（镜像） | x+1 | x−1 | y0 |
| F4 480ms | 通过 | 原位 | y−2（抬起） | y−1 |

腿不动，只有鞋位移；手臂反向摆。整段位移用容器 transform，**分段 easing** 见 §3.2。

## 2. 横向场景的交接（`d3.html`，12s 一轮）

0–1.0s 待机 → 1.0–3.6s 走到中间 → 3.6–4.2s 递出（卡片平放 8×3）→ 4.2–4.6s 飞行（翻成立起 6×8）→
4.6–4.75s 接住（抬手 1px 回弹）→ 5.6–8.8s 走回 → 8.8–12s 待机。

## 3. 纵向走廊（`d3-vertical.html`，18s 一轮）

### 3.1 工位几何

| 元素 | 300 宽 | 380 宽 |
|---|---|---|
| 面板 / 走廊内容宽 | 300 / 284 | 380 / 364 |
| 工位 `.seat` | **104 × 80** | 150 × 80 |
| 人物槽 `.mascot` | **44 × 46**（原生 1×） | 同左 |
| 椅背 `.chair` | 34 × 27 | 34 × 27 |
| 显示器 `.monitor` | 34 × 34（屏幕 30×20 + 支架 + 底座） | 同左 |
| 桌面 `.desk-top` | 104 × 10（**2px 高光边** + 1px 压边） | 150 × 10 |
| 桌前挡 `.desk-front` | 104 × 12 + 两侧 5×16 桌腿 | 150 × 12 |
| 铭牌 `.plate` | 22 高 | 22 高 |
| 过道 `--aisle` | **46** | **56** |
| 行高 / 行距 | 80 / 10 | 80 / 10 |

**排布 = 交错单列**：8 行、一人一行、左右交替、过道在中间（`grid-template-columns:1fr var(--aisle) 1fr`）。
走廊总高 8×80 + 7×10 = **710**，底部另加 28 高地面条（绿植 + 猫）。
侧栏本来就能滚，不为了塞进一屏把桌子做小。

### 3.2 走路路径与时长

小前在 1 号（row1 左），目标 3 号（row3 左），**两行 = 180px**：

| 段 | 位移 | 时间 | 步数 |
|---|---|---|---|
| 出座（桌 → 过道） | `translateX var(--desk-dx) → 0` | 1.2–2.0s | `steps(8)` |
| 下楼（row1 → row3） | `translateY 0 → 180px` | 2.0–4.6s | 前段 `steps(40)` 走 160px，后段 `steps(5)` 只走 20px |
| 回程 | 反向 | 9.4–12.8s | 同上 |

`--desk-dx`：300 时 −112、380 时 −155（工位宽 104/150 决定）。
减速靠分段 easing：同一段里前 2.1s 走 160px、最后 0.5s 只走 20px —— 步频不变、步幅骤减，读起来是刹住。

### 3.3 交接时序（18s 归一化）

| 时间 | 事件 | 实现 |
|---|---|---|
| 4.6–5.2s | 小前到站、转向小审 | `walker .pose[data-p="give"]` 前摇 |
| 5.2–6.4s | **递出**：平放卡在手 | `card:'take'` 画在精灵里 |
| 6.4–6.9s | **飞行**：平放 → 立起，`0 → −19px`（380 时 −24） | `.card-fly` 内两层 `<i>` 切 opacity |
| 6.9–7.1s | **接住**：小审手臂抬 1px（150ms） | `arms:'catch'` |
| 7.1–8.6s | **点头**：头下移 1px，两拍 | `headDy:1` 姿态 |
| 8.6–9.4s | 小审回座（工位精灵淡入） | `rvAway` |
| 9.4–12.0s | 小前走回 1 号 | 反向 keyframes |
| 12.8–18.0s | 全员待机 + 生活感小动作 | 见 §3.5 |

### 3.4 z-index 层序（重要）

| 层 | z | 说明 |
|---|---|---|
| 椅背 `.chair` | 0 | 在人物**身后**，左右各露出 6–7px |
| 人物 `.mascot` | 1 | 在桌子上方、桌面遮挡条**之下** → 脚被桌面切掉 |
| 显示器 `.monitor` | 2 | 坐在桌面线上（`bottom:44px`） |
| 桌面 / 桌前挡 / 桌腿 | 3 | 正面遮挡条：盖住人物脚部与显示器底座 |
| 铭牌 `.plate` | 4 | 最上层，桌腿从它两侧穿过 |
| 走动人 `.walker` / 串门 `.guest` | **5** | 在桌子**前面**，会挡住显示器 |
| 文件卡 `.card-fly` | **6** | 永远最上层，飞过过道不被任何东西盖住 |
| 过道底 `--aisle` / 地面条道具 | 0 | 只做底色，不参与遮挡 |

小审串门时工位上那个精灵 `opacity:0`（`rvAway`），过道边的 `.guest` 接替 —— **同一个角色不会同时出现两份**。

### 3.5 生活感小动作（纯 CSS，无 JS 计时器）

| 角色 | 动作 | 周期 | 窗口 | 错开 |
|---|---|---|---|---|
| 老后 | 喝咖啡（右臂抬 + 6×6 杯到嘴边） | 13s | 72%–86% | 无 delay |
| 小设 | 伸懒腰（双臂上举） | 11s | 46%–58% | `delay:-3.4s` |

两个姿态各是一份完整精灵（`.base` / `.act`），互补 opacity keyframes 硬切。

### 3.6 圆形头像（正式代码形状）

| | 36 圆 | 24 圆 |
|---|---|---|
| 画布 | 36×36 | 24×24 |
| 安全区 | **r=16**（内容只画在圈内） | **r=10** |
| 状态环 | 2px `inset box-shadow`，压在 r=16–18 | 2px，压在 r=10–12 |
| 头 | 16×16（x10–25, y8–24） | 10×10（x7–16, y7–17） |
| 肩 | 30×9（y26–34），被圆弧自然切掉 | 20×7（y17–24） |
| 眼 | **3×3 实心**（x12/x21, y14） | 2×2 |
| 细节 | 眉/嘴/腮红（固定粉，不用身份色） | 无 |

环的动效：`working` / `waiting` → `ringPulse`（1.9s 呼吸）；`provisioning` → 2px 虚线环 `spin` 3.2s；
`done` → 双环（实环 + 1px 淡外环）。列表项外层 `border-radius:50%`，与正式代码 `.wt-avatar-wrap` 一致。

## 4. 七态微动

| 状态 | 姿态 | 微动 | 周期 | 徽标 |
|---|---|---|---|---|
| idle | 站姿 | 呼吸 + 眨眼 | 2.8s / 4.6s | 无 |
| working | 双手在键盘上 | 左右手反相 `±1px`、身体轻浮 | 0.42s / 1.7s | 无 |
| waiting | 右手举起 | 右脚点地 `−2px`、`?` 上下 1px | 0.9s / 2.2s | `?` 琥珀 |
| done | 双手举起 | 起跳 3px，落下长停 | 2.6s | `✓` 绿 |
| error | X 眼 | 左右抖 `±1px` | 0.9s | `✗` 红 |
| failed | 闭眼、头低 1px | 透明度 `0.55 ↔ 0.82`，脚下虚线 | 3.4s | `✗` 红 |
| provisioning | 闭眼 | 闪 `1 ↔ 0.5`，左侧 3 个蓝点上浮 | 1.8s / 1.2s | `…` 蓝 |

状态色只出现在**徽标 / 铭牌点 / 头像环**，衣服永远是身份色。

## 5. 降级与控件

- **`prefers-reduced-motion`**：全部 `animation:none`，静止在首帧。首帧必须自身完整：
  睁眼、演员停在各自工位（静态 `transform` 兜底必须写死）、飞卡 `opacity:0`、串门的 guest 不可见。
- **速度 0.5× / 1× / 2×**：统一 `--speed`，`animation-duration: calc(基准 / var(--speed))`；只改时长不改位移。
- **暂停**：`.paused *{animation-play-state:paused}`。

---

## 6. 接正式代码时的硬约束

1. **身份色与状态色永不同元素**：`--c-shirt` 只给衣服；状态色只给徽标 / 铭牌点 / 头像环。
2. **每个角色 6 色**（ink / skin / hair / shirt / pants / shoe）+ 共享道具色；三阶明度用 `color-mix`。
3. **深色主题提亮不降饱和**：`--px-skin` `#f4c8a2 → #ffd6ae`、`--px-blue` `#2d7ff9 → #5a9bff`。
4. **暗色描边单独一档**：`--px-ol` 亮色 = ink `#241c18`，暗色 = ink + 22% 白 `#544e4b`。
5. **家具用中性灰**（桌面 / 桌前挡 / 椅背各一档 + 1px 压边），不抢人物；桌腿必须画，否则桌子像浮条。
6. **像素稿不做非整数缩放**：44×46 槽放 44×46 原生稿；32×40 只用于横向 demo。
