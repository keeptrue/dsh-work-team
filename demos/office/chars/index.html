A

圆角小人

人 · 软渐变

把「人」放在第一眼：大头、亮脸、实心眼，靠发型/头饰/道具认人。最像 Marvis，也最稳。

  • 32px 眼睛 2.9×3.4px 纯色，脸永远是全身最亮的地方
  • 剪影 呆毛 / 耳机 / 头巾 / 蘑菇头 / 双丸子 / 贝雷 / 帽檐 / 丸子
  • 体形 老后胖一档、老运壮一档；小研矮一档、小审矮半档
打开 d1.html →
B

团子兽

兽 · 粗描边

重画，不是修。扁平色块 + 统一墨线，耳朵和尾巴负责剪影，表情夸张一档。最有性格。

  • 32px 眼 3.4px（比 A 大 20%），墨线 1px 把色块钉住
  • 8 物种 猫 / 兔 / 熊 / 狗 / 狐 / 羊 / 浣熊 / 鸟，没有一只靠颜色区分
  • 风险 幼态、贴纸感；128px 精致度不如 A
打开 d2.html →
C

像素小人

像素 · 网格

1× 就是最终稿，32px 天生对齐；4× 只用于展示和文档。最省实现，也最「工具」。

  • 32px 2×2 实心深色眼睛、1px 深色描边，没有抗锯齿灰边
  • 简化稿 头发收成一块实色，道具只留一个像素特征
  • 风险 128px 放大后细节少；气质偏复古，不一定配现在的 UI
打开 d3.html →

怎么验

三份 demo 的顶栏控件一致：主题 / 宽度 / 暂停 / 速度 / 重播交接

32px 真尺寸

每页 02 区是一条 300px 侧栏，里面就是 32px 的最终渲染。把浏览器缩到 100%，退后一臂看这一条。

七种状态

每页 03 区：待命 / 干活中 / 等你回复 / 有新结果 / 异常结束 / 入职失败 / 入职中。状态靠姿态 + 眼型 + 嘴型，颜色只是最后一道保险。

微场景

每页 04 区：3 个工位、显示器光、私人物品、地毯；阿策起身 → 前倾递文件 → 小研接住下沉 → 点头 → 回座，18 秒一循环。

这一轮只做角色

布局、状态机、七态语义、走廊结构一律没动；三个方向都只改「怎么画」。正式代码（client.js / lib / locale / docs / test）零改动。

文件
